# 01.HTML

Учебный проект по лабораторной работе №1 «Основы HTML».

## внутри

- `index.html` — главная страница.
- Слева находится меню лабораторных работ и заданий.
- Справа находится одно рабочее окно `iframe`.
- Любая ссылка из меню открывает задание в этом же правом окне.
- `lab1_part1` — задания 1–10 + индивидуальное задание.
- `lab1_part2` — задания 11–23.
- `lab1_part3` — задания 24–34.
- `assets` — локальные учебные картинки.
- `style.css` — общий CSS.

JavaScript в проекте **пока нету**.

## Как запустить через VS Code и Five Server

1. В дереве файлов нажать правой кнопкой по:

   `01.HTML/index.html`

2. Выбрать:

   `Open with Five Server`

3. Откроется адрес примерно такого вида:

   `http://127.0.0.1:5500/01.HTML/index.html`
