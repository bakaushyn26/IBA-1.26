# 01.HTML


## Проект

Главный файл:

```text
index.html
```

Слева на странице находится меню с лабораторными работами и заданиями.  
Справа — одно рабочее окно `iframe`, в котором открывается выбранное задание.

Поэтому каждое задание не открывается в новой вкладке браузера.

Структура заданий:

- `lab1_part1` — задания 1–10 и индивидуальное задание;
- `lab1_part2` — задания 11–23;
- `lab1_part3` — задания 24–34;
- `assets` — картинки, используемые в заданиях;
- `style.css` — общие стили;
- `welcome.html` — стартовая страница в правом окне;
- `index.html` — главная страница проекта.

## Как запустить через VS Code

1. Открыть папку `01.HTML` в VS Code.

2. Найти файл:

```text
index.html
```

3. Нажать по нему правой кнопкой мыши.

4. Выбрать:

```text
Open with Five Server
```

5. Страница откроется в браузере примерно по адресу:

```text
http://127.0.0.1:5500/index.html
```

## Как работает меню

Пример ссылки в меню:

```html
<a href="lab1_part1/task01.html" target="work">
    Задание 1
</a>
```

Справа находится окно:

```html
<iframe name="work" src="welcome.html">
</iframe>
```

Атрибут:

```text
target="work"
```

говорит браузеру открыть страницу именно в этом `iframe`.

То есть схема простая:

```text
меню слева
    ↓
выбор задания
    ↓
задание открывается справа
```
